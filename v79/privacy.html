Уведомление о конфиденциальности

Редакция: 2 августа 2026 года. Рабочий проект для юридической проверки перед коммерческим запуском.

Какие данные обрабатываются

CRYPTO LAB может обрабатывать email и технический идентификатор аккаунта, имя профиля, язык, часовой пояс, тариф, дневные счётчики использования, избранные активы и данные портфеля, которые пользователь вводит самостоятельно.

Для чего используются данные

Данные нужны для регистрации и входа, восстановления доступа, сохранения настроек, синхронизации портфеля, применения тарифных лимитов, предотвращения злоупотреблений, поддержки сервиса и обработки заявок на тариф.

Сторонние сервисы

Для работы платформы могут использоваться Supabase для аккаунтов и базы данных, GitHub Pages для размещения интерфейса, Binance для публичных рыночных данных и OpenAI для AI-анализа. Передаваемый AI-контекст ограничивается вопросом пользователя и рыночными данными, необходимыми для ответа.

Безопасность и хранение

Секретные серверные ключи не должны храниться в браузере. Доступ к пользовательским таблицам ограничивается политиками Row Level Security. Сроки хранения определяются назначением данных, требованиями безопасности и необходимостью работы аккаунта.

Выбор пользователя

Пользователь может изменить данные профиля, удалить активы портфеля и прекратить использование сервиса. Запрос на удаление аккаунта и связанных данных будет добавлен в интерфейс до публичного коммерческого запуска.

Контакты и изменения

Контакт оператора и юридическое лицо должны быть добавлены до приёма платежей. Существенные изменения уведомления должны публиковаться с новой датой редакции.

Этот текст не заменяет консультацию юриста и должен быть адаптирован под фактическую юрисдикцию, способ оплаты и модель бизнеса.
